Principais Features: ✅ API RESTful com Express.js para gerenciar produtos. 
🔐 Segurança: Autenticação com JWT e criptografia de senhas usando bcrypt. 

📚 Documentação: Endpoints documentados e prontos para teste com Swagger (OpenAPI). 

🏗️ Arquitetura: Código organizado no padrão MVC para facilitar a manutenção. 

⚙️ Boas Práticas: Gerenciamento de dados sensíveis com variáveis de ambiente (.env).
